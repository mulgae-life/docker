뉴 간단 한국어 가동 후기는 공신력 있는 한국어 LLM 벤치마크가 아님. LLM 버전 출발 드림팀이나 위험한 초대 정도?

벤치라는 이름을 가지고 있는 질문들도 진지한 의미의 벤치마크가 아닌, 해당 질문이 처음 등장하던 시절에 LLM에서 실패하는 경우가 많아 농담으로 벤치마크라고 부르는 것들임.

1. 모델에 대해서

Qwen 3.8 27B는 중국 알리바바에서 개발한 모델로서 총 27B 크기를 가진 일반(Dense) 모델이다. 이미지 입력 기능도 가지고 있으나 이 가동 후기에서는 사용하지 않는다.

2. 모델 구동 세팅

OS - Fedora 44 KDE (리눅스)

소프트웨어 - lama.cpp b10435 다음 중 어딘가 버전(9d57ce4) 수동 CUDA 빌드

양자화 - IQ3_M (3.66 BPW)

하드웨어 - 평범한 하이엔드급 게이밍 컴퓨터

CPU - AMD 라이젠 7 9800X3D 8코어 프로세서

GPU1 - 엔비디아 4080 Super 16GB 외장 그래픽카드 (AI 연산)

GPU2 - CPU 내장 라데온 그래픽카드 (화면 표시)

RAM - DDR5 64GB 5600

SSD - PCI-e 4.0 2TB SSD (가상메모리 겸용)

IQ3_M 양자화를 사용하기에 약간의 성능 불이익이 있을 수 있다. 샘플링은 공식 권장 세팅에 맞춰 설정.

구동 옵션 - ./llama-server -t 16 -c 65536 -ctk q4_0 -ctv q4_0 -ngl all -m Qwen3.8-27B-IQ3_M.gguf --temp 1.0 --top-p 0.95 --top-k 20 --min-p 0 --presence-penalty 0 --repeat-penalty 1.0

해당 모델은 추론 기능을 기본으로 사용한다.샘플링도 추론 기능 사용 시의 권장 세팅을 사용한다.
